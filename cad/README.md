# LUMA CAD files

Open `assembly.scad` in OpenSCAD to view the entire assembled lamp with the standard 1.85-inch head, or `assembly_dsi.scad` for the optional 4-inch DSI head. Both import the supplied meshes with the positions and colors in `assembly.json` / `assembly_dsi.json`; `assembly_preview.scad` is an equivalent copy of the standard preview. Edit individual part geometry in `luma.scad` and select its `part` parameter using an ID from `part_manifest.json`.

Print the standard build from the 26 files in `stl/` whose manifest `variant` is `standard`, in the quantities from `part_manifest.json` (44 physical pieces including the fit coupon and the optional cable clips). The optional 4-inch DSI head adds `head_shell_dsi`, `lcd4_carrier`, `face_ring_dsi` and `brow_bracket` and omits `head_shell`, `face_center`, `white_carrier`, `inner_diffuser`, `lcd_cradle` and `lcd_retainer`. Read the print orientation for each piece: the four arm link halves print plate-down, the head fork prints on its mounting plate rotated 180 degrees about X. Do not print anything from `visual_only/`: it contains purchased-component envelopes and complete assembled reference models for viewing.

The exact OpenSCAD executable location defaults to `C:/Program Files/OpenSCAD/openscad.com`; override it with the `OPENSCAD` environment variable if needed. Run `python cad/build.py` from the project root with NumPy and trimesh installed to regenerate every asset, or `python cad/build.py upper_arm_left forearm_left` to re-export only the named parts. The hidden electronics tray uses 32 facets to keep exports practical; all dimensions remain the same. `cad/refresh_validation.py` measures existing STLs without re-exporting them.

`ballast_plate.dxf` contains a 180 mm steel disc outline and eight drill circles in millimetres. Its thickness is 6 mm; the DXF is 2D, not an instruction to print the ballast. The dimensioned SVG drill template is on a 250 x 230 mm page, suitable for an actual-size A3 print.

`validation.json` records mesh integrity, connected bodies, dimensions and solid volume. `purchased_fit.json` records a static conservative servo/LCD-envelope fit check for both assemblies; `../validation/assembly_check.json` records printed-part intersections at indexed neutral for both. These reports do not replace a physical fit, load, thermal or motion test.

`mechanical.md` provides the assembly instructions and assumptions. `bom_mechanical.csv` lists metal, hardware and printing consumables (rows starting with `D` belong to the optional head); the complete project BOM also includes the electronics list. Vendor STEP/DXF/PDF reference files, including the Waveshare 4inch DSI LCD (C) drawing and STEP archive used to measure the optional head, are stored separately in `references/` and remain their vendors' material.
