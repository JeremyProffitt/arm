# LUMA CAD files

Open `assembly.scad` in OpenSCAD to view the entire assembled lamp with the standard 1.85-inch head, or `assembly_dsi.scad` for the optional 4-inch DSI head. Both import the supplied meshes with the positions and colors in `assembly.json` / `assembly_dsi.json`; `assembly_preview.scad` is an equivalent copy of the standard preview. Edit individual part geometry in `luma.scad` and select its `part` parameter using an ID from `part_manifest.json`.

Print the standard build from the24 files in `stl/` whose manifest `variant` is `standard`, in the quantities from `part_manifest.json`. The optional4-inch DSI head adds `head_shell_dsi`, `lcd4_carrier` and `face_ring_dsi`, and omits `head_shell`, `face_center`, `white_carrier`, `inner_diffuser`, `lcd_cradle` and `lcd_retainer`. Revision C has no printable sensor pods, retainers or brow bracket: all five Adafruit3967 boards screw directly to bosses inside the pedestal wall. The four arm halves print plate-down, and the head fork prints on its mounting plate rotated180 degrees aboutX. Do not print anything from `visual_only/`; it contains purchased-component envelopes and complete assembled references.

The exact OpenSCAD executable location defaults to `C:/Program Files/OpenSCAD/openscad.com`; override it with the `OPENSCAD` environment variable if needed. Run `python cad/build.py` from the project root with NumPy and trimesh installed to regenerate every asset, or `python cad/build.py upper_arm_left forearm_left` to re-export only the named parts. The hidden electronics tray uses 32 facets to keep exports practical; all dimensions remain the same. `cad/refresh_validation.py` measures existing STLs without re-exporting them.

`ballast_plate.dxf` contains a 180 mm steel disc outline and eight drill circles in millimetres. Its thickness is 6 mm; the DXF is 2D, not an instruction to print the ballast. The dimensioned SVG drill template is on a 250 x 230 mm page, suitable for an actual-size A3 print.

`validation.json` records mesh integrity, connected bodies, dimensions and solid volume. `purchased_fit.json` checks conservative DS3218MG, pedestal-sensor and display envelopes in both assemblies; `../validation/assembly_check.json` records printed-part intersections at indexed neutral. These reports do not replace a physical horn/bearing fit, load, electrical, thermal or moving-clearance test.

`mechanical.md` provides the assembly instructions and assumptions. `bom_mechanical.csv` lists metal, three625 idler bearings, hardware and printing consumables. Rows starting with `D` belong to the optional head. The complete BOM also includes the inventory DS3218MG servos, user-selected PCA9685 and6V regulator. Vendor geometry sources are identified in `docs/sources.json`.
